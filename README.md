# PLSI Lab for Cursor

Cursor plugins from [PLSI](https://longevitygrok.si/).

| Plugin | What it does |
|---|---|
| [`lab-journal`](plugins/lab-journal/) | A wet-lab notebook with versions, signing and tested bench numbers |
| [`lab-report`](plugins/lab-report/) | A blood test read with tested code, and your blood-test age |
| [`trial-scout`](plugins/trial-scout/) | Recruiting clinical trials near you, with eligibility checked |
| [`med-check`](plugins/med-check/) | FDA label warnings that name your other medicines and supplements |
| [`visit-prep`](plugins/visit-prep/) | A printable one-page summary before a doctor's visit |

Check the repository with `node scripts/validate-template.mjs`.
