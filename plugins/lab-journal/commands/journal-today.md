name: journal-today
description: The day in the lab journal: plan, running experiments with their next step, flags
---

Use the `lab-journal` skill. Run `lj today` and give, in a few lines: the open items in time order, each running
experiment with its next step, and the flags. If the researcher added text after the command, it is a change to
today's plan ("done: ...", "add: 14:00 ..."): apply it with `lj day save` first.
