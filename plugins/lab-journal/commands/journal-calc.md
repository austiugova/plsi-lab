Use the `lab-journal` skill. Turn the researcher's request after the command into `lj calc --kind <kind> --set
name=quantity ...` (see `lj calc --help`), and give the result with its steps as the code printed them. Never
do the arithmetic yourself; a calculation the journal lacks is "not in this journal yet".
